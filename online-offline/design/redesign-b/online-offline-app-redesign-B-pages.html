New primitives

Built once, shared

Anatomy and states. Full spec in README-pages.md.

InputLabel 10px mono above. Value 16px sans (or 26px serif for titles). Bottom hairline `--line2`; `--ink` on focus; placeholder `--ink3`. No box, no radius.
SelectInput + 12px chevron right. Opens native sheet on mobile.
TextareaInput rules, min 90px, auto-grow. Serif 17px for creative text (poem, prompt, message).
WordCountRight-aligned 11px mono gold; turns orange past limit.
SegmentedToggle1px `--line2` box, 6px radius; active segment `--bg2` + ink.
ChoiceCardSerif title + 11.5px desc, 8px radius; active border takes accent.
FocalPointFrameImage frame 10px radius. Crosshair 44px, 1px lines + 16px ring, accent color; "Crop center x%, y%" mono bottom-left; optional ★ Feature bottom-right; × top-right.
ThumbStrip56px squares, 7px radius, 8px gap; current = ink border; ★ marks feature; dashed + slot; "n / 8" mono right.
SearchField44px, icon left, bottom hairline only. Results are RosterRows.
RosterRow32px initial avatar, serif name, 11px mono sub, right slot: type tile / button / 7px status dot.
PillFrom B: 34px, icon + mono. Adds label variant (Join / Joined / city).
BriefCollapsible prompt panel, 1px `--line2`, 10px radius, gold PROMPT label, serif 16px body.
ProgressStepsn bars 2px, ink for done. "2 / 3" mono in header.
Toggle40×22, gold when on.
StatusDot7px: green accepted, `--line2` pending, orange declined.
