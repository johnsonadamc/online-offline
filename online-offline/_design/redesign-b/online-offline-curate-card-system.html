Curate · one card, four tabsEvery tab is a grid of page cards. One card is one page you could put in the issue. Same anatomy, same two gestures, same states. Only the cover and the control slot change per tab.
Anatomy + rules

The page card

Four fixed slots. Nothing else goes on a card.

Coverimage · brand · type tint · quote
Titlename, one line, ellipsis
Metaone mono value, right
Controlcheck · pills · request
Two gestures, everywhere
  • Tap the card to select it (or tap a pill when there are variants). Green disc appears top-right, border turns green, meter fills one page, price ticks.
  • Tap the cover to expand: the card spans both columns and shows its detail (bio, description + prompt, cities, messages). Tap again to collapse.
States, identical on all tabs
  • Selected: green disc + green border.
  • Issue full (0 open): unselected cards dim to 40%.
  • Locked: lock on cover, Request access in the control slot, then "Request sent".
  • Read-only (comms previews): dashed border, no control.
  • Yours: gold dot in the control slot.
