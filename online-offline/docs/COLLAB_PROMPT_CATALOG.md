## Editorial rule

**Prompts about results fail; prompts about evidence of time succeed.** A prompt should ask for what time
leaves behind (a place used, returned to, kept, unfinished), never for an achievement or a finished product.

## Catalogue

| Prompt | Constraint | Mode |
|---|---|---|
| Disuse / former lives | visible from the street, still standing; caption names the former life | Local (Pensacola) |
| Rise and shine | the first thing you see *outside* (forces morning light) | Private |
| The water you don't photograph | bayous, retention ponds, drainage cuts — or blue hour only | Local |
| Where you listen | the place, not the album | Community |
| The same corner, once a week | fixed spot, fixed framing | Community |
| What you kept | one object moved house with and never used (portrait-friendly) | Private |
| Still working on it | the unfinished thing, not the result | Community |
| Tuesday dinner | the pot, not the plate; food when nobody's coming | Private |

**Modifier:** black-and-white or a single colour can attach to any prompt. It is never a prompt by itself.

## Mode rule

Subjects that are inherently similar read as a **series** in Private (2–3 images), but as a **menu** in a
6-cell Community spread. Give Community and Local the prompts whose answers differ a lot from each other.
Keep the look-alike subjects for Private.

## Rejected as written

| Prompt | Why | Became |
|---|---|---|
| "Photograph an accomplishment" | doesn't photograph: a result, not evidence | folded into *Still working on it* |
| "Food you've cooked" (plated) | a plated dish reads as a menu | *Tuesday dinner* |
| "Trust the Process" | hustle-culture title, selfie-dependent | folded into *Still working on it* / "what the routine leaves behind" |
| "At the water" (unconstrained) | no constraint, so no series | *The water you don't photograph* |

copy three's content and the real doability test. The eight-prompt list goes to one outside photographer,
who is asked which two they would shoot.
